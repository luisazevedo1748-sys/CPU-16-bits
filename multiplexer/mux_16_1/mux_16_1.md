# 16:1 Multiplexer

The 16:1 mux works like the 8:1, 4:1 and 2:1, but selects 1 data path out of 16
for a single output (`Out`). This level of selection needs 4 control bits
(S3, S2, S1, S0).

The 16 data inputs arrive as a single 16-bit bus, `D_In`: bit `k` of `D_In` is
data line `k`. (Earlier versions of this block took 16 separate `D0`…`D15`
pins; the circuit was rewired to a bus input in Digital — same function, one
pin instead of sixteen.)

Following the same logic as the 4:1 mux, the process has 2 stages:

**Stage 1 (pre-selection)** — two 8:1 mux blocks operate in parallel, sharing
the 3 least significant select bits (S2, S1, S0). The upper block picks among
`D_In[0..7]`, the lower block among `D_In[8..15]`.

**Stage 2 (final decision)** — a 2:1 mux block takes the 2 filtered signals and
uses the most significant select bit (S3) to route the chosen input to `Out`.

Truth table (`D_In[k]` is bit `k` of the input bus):

| S3 | S2 | S1 | S0 | Output |
|----|----|----|----|--------|
| 0 | 0 | 0 | 0 | D_In[0]  |
| 0 | 0 | 0 | 1 | D_In[1]  |
| 0 | 0 | 1 | 0 | D_In[2]  |
| 0 | 0 | 1 | 1 | D_In[3]  |
| 0 | 1 | 0 | 0 | D_In[4]  |
| 0 | 1 | 0 | 1 | D_In[5]  |
| 0 | 1 | 1 | 0 | D_In[6]  |
| 0 | 1 | 1 | 1 | D_In[7]  |
| 1 | 0 | 0 | 0 | D_In[8]  |
| 1 | 0 | 0 | 1 | D_In[9]  |
| 1 | 0 | 1 | 0 | D_In[10] |
| 1 | 0 | 1 | 1 | D_In[11] |
| 1 | 1 | 0 | 0 | D_In[12] |
| 1 | 1 | 0 | 1 | D_In[13] |
| 1 | 1 | 1 | 0 | D_In[14] |
| 1 | 1 | 1 | 1 | D_In[15] |
