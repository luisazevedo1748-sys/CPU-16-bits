# 16:1 Multiplexer

The 16:1 mux works like the 8:1, 4:1 and 2:1, but lets us select 1 data path out
of 16 inputs (D0 to D15) for a single output (Y). This level of selection needs
4 control bits (S3, S2, S1, S0).

Following the same logic as the 4:1 mux, the process has 2 stages:

**Stage 1 (pre-selection)** — two 8:1 mux blocks operate in parallel, sharing
the 3 least significant select bits (S2, S1, S0). The upper block picks between
D0 and D7, the lower block picks between D8 and D15.

**Stage 2 (final decision)** — a 2:1 mux block takes the 2 filtered signals and
uses the most significant select bit (S3) to make the final decision and route
the chosen input to the output (Y).
